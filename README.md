# Leather Stitch Array для LibreCAD 2.2.1

Нативный плагин C++/Qt создаёт CAD-объекты `CIRCLE` вдоль одной выбранной `LINE`, `ARC` или `POLYLINE`. Окружности создаются на текущем активном слое; исходная геометрия не изменяется.

## Возможности

- точный шаг по длине прямых и круговых дуг, без линейной аппроксимации;
- единый шаг через вершины полилинии;
- поддержка положительного и отрицательного DXF bulge;
- открытые и замкнутые полилинии;
- режим `Exact Pitch`: установленный шаг сохраняется, остаток попадает в замыкающий промежуток;
- режим `Fit to Perimeter`: периметр делится на ближайшее целое число равных интервалов;
- начальный отступ и прямое/обратное направление;
- сохранение последних параметров через `QSettings`;
- пропуск уже существующих окружностей с теми же центром и радиусом на текущем слое (допуск 0,001 мм);
- ограничение в 100 000 точек на одну операцию.

Предпросмотр, автоматический offset контура и связанные массивы из раздела 8 исходного ТЗ в первую версию не включены.

## Проверенная совместимость среды

На целевой машине установлен LibreCAD `2.2.1.6-1-g05af8d052`, x64. Его `Qt5Core.dll` сообщает: Qt `5.15.2`, x86-64, release, MSVC 2019. Плагин необходимо собирать Qt `5.15.2` для `msvc2019_64`; MinGW-сборка ABI-несовместима.

В текущей среде отсутствуют Qt SDK/qmake, CMake и C++ workload MSVC. Поэтому DLL здесь **не собрана и не проверена загрузкой в LibreCAD**. Папка установки LibreCAD и штатных плагинов найдена, но непроверенная DLL туда не устанавливалась.

## Сборка Windows x64

1. Установите Visual Studio 2019 Build Tools с компонентом `Desktop development with C++` и Qt `5.15.2 msvc2019_64`.
2. Получите официальные исходники совместимой ветки:

   ```powershell
   git clone --branch 2.2.1 --depth 1 https://github.com/LibreCAD/LibreCAD.git C:\src\LibreCAD-2.2.1
   ```

3. Откройте `x64 Native Tools Command Prompt for VS 2019`, перейдите в этот проект и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1 `
     -QtDir C:\Qt\5.15.2\msvc2019_64 `
     -LibreCadSource C:\src\LibreCAD-2.2.1
   ```

Скрипт сначала собирает и запускает тесты геометрии, затем создаёт DLL в `build\plugin`. Он прекращает работу, если версия Qt не равна 5.15.2 или qmake не использует MSVC.

## Бесплатная облачная сборка через GitHub Actions

В проект добавлен workflow `.github/workflows/build.yml`. После загрузки проекта в GitHub он запускается при `push`, pull request или вручную: `Actions -> Build LibreCAD plugin -> Run workflow`.

Workflow использует Windows Server 2019 с MSVC 2019, устанавливает Qt 5.15.2 `msvc2019_64`, получает официальные заголовки LibreCAD 2.2.1, запускает `build.ps1` и публикует готовую DLL как artifact `leather-stitch-array-windows-x64` на 14 дней.

После успешного запуска откройте страницу запуска в GitHub, внизу скачайте artifact, распакуйте его и скопируйте DLL в каталог плагинов LibreCAD.

## Установка и удаление

1. Закройте LibreCAD.
2. Скопируйте полученную `leatherstitcharray1.dll` в:

   ```text
   C:\Program Files\LibreCAD\resources\plugins
   ```

   Для записи в `Program Files` нужны права администратора. Альтернативно передайте этот каталог параметром `-InstallDir` при запуске `build.ps1` из повышенной консоли.
3. Запустите LibreCAD. В меню должна появиться команда `Plugins -> Leather Stitch Array`.

Для удаления закройте LibreCAD и удалите только `leatherstitcharray1.dll` из каталога плагинов. Пользовательские параметры находятся в стандартном хранилище `QSettings` LibreCAD и не влияют на чертежи.

## Использование

1. Запустите `Plugins -> Leather Stitch Array`.
2. Штатным инструментом выбора укажите ровно одну линию, дугу или полилинию и нажмите Enter.
3. В появившейся верхней панели укажите шаг, диаметр, начальный отступ, режим и направление.
4. Проверьте длину, число отверстий, фактический шаг и замыкающий промежуток.
5. Нажмите `Create`. Окружности будут добавлены на активный в этот момент слой.

Plugin API LibreCAD 2.2.1 не предоставляет чтение предварительно выделенного набора, поэтому выбор выполняется после запуска команды. Значения полей интерпретируются как миллиметры. Если `$INSUNITS` явно задаёт другие единицы, операция блокируется; для безразмерного чертежа пользователь отвечает за масштаб 1 единица = 1 мм.

## Тесты

`tests/test_geometry.cpp` проверяет:

- линии 100 мм и 137 мм с шагом 4 мм;
- замкнутые прямоугольники с периметром 40 мм и 41 мм;
- наклонный отрезок;
- Exact Pitch и Fit to Perimeter;
- положительный и отрицательный bulge;
- обратное направление дуги;
- нулевой сегмент и лимит количества отверстий.

Команда тестирования входит в `build.ps1`. Интеграционные проверки загрузки DLL, интерфейса, Undo, сохранения и повторного открытия DXF должны выполняться вручную после реальной сборки.

## Известные ограничения API LibreCAD 2.2.1

- `Document_Interface::addCircle()` самостоятельно создаёт Undo-секцию для каждой окружности. Публичного API для одной общей Undo-транзакции нет, поэтому один Undo-шаг на весь массив гарантировать нельзя.
- API не предоставляет transient preview, поэтому предварительный просмотр не реализован.
- Проверка повторного запуска не создаёт дубли, но не связывает массив с исходным объектом и не перестраивает его после редактирования контура.
- Реальная загрузка DLL, сохранение/повторное открытие DXF и поведение на очень больших реальных чертежах в этой среде не подтверждены.
- Указанный в ТЗ архив `LeatherStitchArray_LibreCAD_Source.zip` среди полученных вложений отсутствовал; проект создан на основе официального API LibreCAD 2.2.1 и официального sample plugin.
